# Yew Starter Template

A minimal starter template for building client-side web applications with Rust and Yew.

## Setup

```bash
rustup target add wasm32-unknown-unknown
cargo install --locked trunk
```

## Local development

```bash
trunk serve --open
```

## Production build

```bash
trunk build --release
```
